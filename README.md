# 🍕 Pizzaria Artesanal

Projeto de um site responsivo para uma pizzaria fictícia, desenvolvido com **HTML5** e **CSS3**, com foco em **layout moderno**, **responsividade** e **boas práticas de Front-End**.

---

## 📸 Visão Geral

O site apresenta:
- Header fixo com navegação
- Seção hero com chamada principal
- Cards de pizzas com imagens e preços
- Seção institucional (“Nossa história”)
- Footer completo com informações de contato
- Layout totalmente responsivo

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**  
- **CSS3**
- **Flexbox**
- **Media Queries**
- **Google Fonts**
- **Font Awesome**
